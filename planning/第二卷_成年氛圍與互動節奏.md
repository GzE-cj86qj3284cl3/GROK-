# 《無主之海》第二卷｜成年氛圍與人物互動節奏

> 依作者2026-11-19新增偏好設定：在冒險主線與日常工作中，增加**非露骨、若隱若現的成年曖昧／擦邊氛圍**；不必每一次有氣氛就發生性交。此為**後續寫作風格指引，不是發生事件清單**。

## 核心方向

1. **氛圍分布於不同場景**：休息室早晨、熱飲與散步、服裝／髮帶／披肩、合法演出後台與舞台剪影、船上工作時臨時貼近、雨夜與轉場的身體距離、成年人之間的玩笑與凝視；每次讓細節具有當下事件的理由，而不是為了填充強行描寫。
2. **若隱若現比直白羅列更有趣**：半透光幕、髮梢、濕外套、錯開眼神、沒有說出口的話。以具有實際人物性格的對話與選擇代替重複描述身形部位；維持非露骨小說風格。
3. **成年場域是生活，不是無休止的說明書**：潮幕庭有成人限定表演、合法感官服務與不同種族的成年旅客，但這些人同時也會排練、加班、吃飯、抱怨設備。避免只讓他們成為主角的陪襯或單純鏡頭特寫。
4. **關係各有溫度**：尹徹偏柔和、耐心、懂得留空間；陸策偏直接、工作上強勢、緊急時可靠，私人曖昧靠共同經驗慢慢累積；聞瀾已發生的第一卷私人關係須保留，不因新增成年男性就將她刪除。
5. **不可抹去工作後果**：曖昧可以發生在工作前後，但不能用親密行為換非法存取權、直接免除責任或讓角色忘記安全程序；第015章的無人艇碰撞與成本，第016章安全門風險應保留。
6. **重大成人場景仍各自獨立**：已發生R18-01／R18-02，詳細狀態以正文為準；後續大綱的R18-03仍保留作為第020章候選。除正式寫入已發生正文的事件外，不在成人資料庫創造新經歷、敏感度量化或憑空提高「淫亂度」數字。
