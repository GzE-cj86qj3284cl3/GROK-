## 倉庫結構

- `world/`：核心世界觀索引與原始設定；正典、已確認補完、候選真相需嚴格區分。
- `characters/`：雪鴨核心設定與最新劇情狀態。
- `chapters/`：正式章節路徑；目前均屬新版初稿。
- `memory/`：故事總摘要、目前進度、人物狀態、角色關係及未回收伏筆。
- `planning/`：寫作規則、後續方向、時間線、場景擴寫、驗收及修訂報告。
- `scripts/validate_chapters.py`：正文漢字數統計，避免以 UTF-8 bytes 誤報字數。
- `.github/workflows/`：既有提交監控工作流程；不代表小說品質已通過驗收。
