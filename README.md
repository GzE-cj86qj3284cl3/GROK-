# 雪鴨的故事

第三人稱有限視角長篇成人向輕小說。

**主角**：雪鴨  
**世界觀**：後奇點多種族共同文明，阿卡夏治理，契約至上。

## 目錄結構

- `world/`：世界觀、制度、地理與歷史設定
- `characters/`：主要人物與能力設定
- `chapters/`：正式章節（每章獨立檔案，**禁止覆蓋或刪除舊章**）
- `memory/`：劇情摘要、人物狀態、關係、伏筆
- `planning/`：後續方向、構想庫、寫作指引

## 寫作核心規則

- 嚴格遵守 `world/00_核心世界觀.md` 的核心既定設定
- 第三人稱有限視角，緊貼雪鴨認知
- 展示而非說明（Show, don’t tell）
- 章節檔案命名：`第XXX章_標題.md`
- **舊章節不可覆蓋或刪除**
- 記憶與狀態文件可持續更新
- **字數目標**：每章目標 **8,000 字以上**
- **避免劇情迴圈**：禁止只重複「殘熱 + 等待」模式，需加入小事件、環境變化或內心衝突推進
- 詳細指引請參考 `planning/寫作指引與注意事項.md`
