# 《無主之海》｜系列小說

> **原開發名：《雪鴨的故事》**。2026-11-17 作者授權以第一卷的單行本品質為目標重構，並允許變更作品／章節名稱。**《無主之海》為此輪採用的暫定出版名**，並非把私人海島誤設為無人管轄領地；「無主」指的是雪鴨不再被他人持有或安排的人生。
