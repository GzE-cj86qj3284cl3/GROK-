# 《無主之海》｜系列小說

> **原開發名：《雪鴨的故事》**。2026-11-17 作者授權以單行本品質為目標重構，並允許調整作品與章節名稱。**《無主之海》為此輪採用的暫定出版名**——並非把私人海島誤設為無人管轄領地；「無主」指的是雪鴨不再被他人持有或安排的人生。

- **類型**：成人科幻冒險／契約與身分懸疑／成年世界的個人自主權（第三人稱有限視角）
- **背景世界觀**：多智慧種共存的後奇點文明。阿卡夏秩序完整，卻不是全知裁判，也不保證每份法律有效的交易都公平。最高正典：[`world/01_核心世界觀原本.md`](world/01_核心世界觀原本.md)
- **主角設定**：**雪鴨（Snowduck）**——具法定成人自主資格的退網萬事屋（147 cm／38 kg 平胸嬌小成人體型、及腰銀白長髮、淡紅眼眸、小腹下方具淡粉紅翼狀個人紋樣；表面淡漠寡言、內心活動豐富可愛；精通各式體位與調教技巧但自身高敏感耐性極低、熱愛泡湯放空與收集稀有古怪小物）。完整設定與七張官方概念設計圖詳見 [`characters/雪鴨.md`](characters/雪鴨.md) 與 [`characters/雪鴨/`](characters/雪鴨/README.md)。
- **當前寫作與驗收總覽**：已完稿 **22 章（第 001～022 章）**，累計 **213,320 正文漢字**（全數通過 `scripts/validate_chapters.py` 單章 ≥ 8,000 漢字門檻）。
