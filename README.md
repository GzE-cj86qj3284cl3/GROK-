# 雪鴨的故事

第三人稱有限視角長篇成人向輕小說。

主角：雪鴨  
世界觀：後奇點多種族共同文明，阿卡夏治理，契約至上。

## 目錄結構

- `world/`：世界觀、制度、地理與歷史設定
- `characters/`：主要人物與能力設定
- `chapters/`：正式章節（每章獨立檔案，**禁止覆蓋或刪除舊章**）
- `memory/`：劇情摘要、人物狀態、關係、伏筆
- `planning/`：後續方向與構想庫

## 創作規則摘要

- 嚴格遵守 `world/00_核心世界觀.md` 的核心既定設定
- 第三人稱有限視角，緊貼雪鴨認知
- 展示而非說明
- 章節檔案命名：`第XXX章_標題.md`
- 舊章節不可覆蓋或刪除
- 記憶與狀態文件可持續更新
