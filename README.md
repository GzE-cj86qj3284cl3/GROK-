# 《無主之海》｜系列小說

> **原開發名：《雪鴨的故事》**。2026-11-17 作者授權以第一卷的單行本品質為目標重構，並允許變更作品／章節名稱。**《無主之海》為此輪採用的暫定出版名**，並非把私人海島誤設為無人管轄領地；「無主」指的是雪鴨不再被他人持有或安排的人生。

**類型**：成人科幻冒險／契約與身分懸疑／成年世界的個人自主權。第三人稱有限視角，主角雪鴨是具有法定成人自主資格的退網萬事屋。背景為多智慧種共存的後奇點文明：阿卡夏秩序完整，卻不是全知裁判，也不保證每份法律有效的交易都公平。最高正典：[`world/01_核心世界觀原本.md`](world/01_核心世界觀原本.md)。
