## 故事第一卷主線

1. **D0／第001～004章**：雪鴨接受匿名金屬片委託、赴灰域取回物件，在排水故障時與獨立成年音訊／場域技術監督**聞瀾**短暫互助。返島後於東側平台與無人艇交收，排除額外生體資料要求；原件交出、報酬與補貼正式結清。
2. **D1～D2／第005～006章**：維修私人海島水路與岸線；退網老人的故人錄音帶出商業再製與同意問題。港口老式播放器委託牽出成人演出音源過期授權爭議，雪鴨與聞瀾協助當事人及店主先停止未確認許可的播放，責任後續走正常程序。
3. **D3～D4／第007～009章**：海霧與雨夜的實際設備風險，浮標位置與訊號不明。雪鴨在合法範圍內逐步取得多來源證據，沒有把各種光點一概歸為監視。同時她與聞瀾的往來從偶遇工作者成為可自主選擇信任的社會關係。
4. **D5／第010章**：在仍可安全使用的東側內側區域進行有限校準，證明曾出現**超出一般公共校準需要的額外識別詢問**，拒絕提供擴充資料；她提交港務技術詢問、主動重申契約界線，並有限度為別人的合法音源權利爭議作證。完成工作程序後，雪鴨主動邀請成年工作者聞瀾於傍晚由西側合法訪客泊位來島相聚；兩人明確確認自願後度過有成人標記、細節待補的親密時光，彼此仍保留未來自由選擇。雪鴨親手歸檔D0已交付的匿名委託、接下普通新工作，形成可獨立閱讀的事件小收尾。
