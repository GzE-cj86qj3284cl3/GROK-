# 成人角色資料庫（memory/adult/）

> 本資料夾專門記錄《無主之海》中已確認的成人親密相關設定、狀態與事件。
> 與一般人物設定、世界觀、主要劇情紀錄嚴格分離。

## 使用原則

1. **僅記錄已寫入正文的事實**，不得把推測、計劃或未發生事件寫成既定歷史。
2. 數值參數若無正文或作者明確設定支持，一律填 `null`。
3. 同一事件只保留一個主紀錄 ID，其他檔案以參照方式連結。
4. 不得反向修改正文以配合資料庫。
5. 涉及年齡／成年身分若有疑點，標記「待確認」，不得自行消除矛盾。

## 目錄結構

- `README.md` — 本說明
- `角色資料/` — 各角色成人向詳細資料
- `事件紀錄/` — 已發生成人事件的詳細紀錄
- `成人狀態參數.json` — 可機讀的參數快照
- `關係與經歷索引.md` — 快速索引
- `設定變更紀錄.md` — 資料庫自身變更歷史
- `待確認事項.md` — 尚未由作者確認的問題

## 維護時機

每次完成成人情節補寫後，必須同步更新本資料夾內相關檔案。
