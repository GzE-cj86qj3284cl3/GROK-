# 第一卷〈潮汐契約〉｜第001～010章（D0～D5，90,588 漢字）

## 主線事實與因果界線
- **D0 金屬片委託**：取回物件、經東側平台無人艇公證交付結算，排除未授權生體資料欄位，僅保留外觀拓印與交接紀錄；委託人意圖與符號意義未證實。
- **聞瀾線與 R18-01**：D0 灰域排水故障結識獨立音訊與感官場域技術監督聞瀾；D2 港區協力停止未確認許可之過期成人互動音源商用播放（責任裁定待程序）；D3～D5 建立互信並做有限公共水位見證；D5 晚間雪鴨主動邀請聞瀾由西側合法訪客泊位入島，雙方自願發生一次成人親密相處（R18-01），事後各自保有獨立生活與未來選擇權。
- **因果界線**：成人音源爭議、金屬片、灰域反光、舊型浮標、東側額外識別詢問與體內未知晶片之間，尚無已證實之共同幕後者。

## 分章摘要
- **第001章　海島的早晨（D0清晨）**：雪鴨獨居私人海島，處理退網老人保留故人含抽風機雜音錄音檔之維修委託；拒絕打包永久感官回放權之成人陪伴報價（A00）；承接匿名高報酬金屬片灰域取件委託並補齊契約條款後出發。
- **第002章　灰域的潮氣（D0上午）**：依一次性憑證進灰域外環，與看守中間人釐清權屬免責；處理積水與老化門鎖、遇共用排水故障而與聞瀾短暫互助並通報公用維護站；取回金屬片並遙控回收量具，避險採保守航線返航。
- **第003章　回島的回響（D0午後）**：導航資料短暫延遲，改以機載感測安全返島；非侵入外觀檢驗未測出主動通訊，偶發腹部溫熱感無法可靠重現；僅向委託人交付契約摘要，規劃海島東側三區隔離交收方案並順手解救受困海鳥。
- **第004章　東側平臺的夜風（D0傍晚）**：側風浪中謹慎完成無人交收艇靠泊、排除額外生體與島內設備資料讀取欄位後結算尾款與補貼；拒絕將主觀感受充作交付資料；對交收時段資料延遲做本地模擬對照並設七十二小時觀測清單。
- **第005章　清晨的殘溫（D1）**：搶修海島海水循環機至六成負載，拒絕用水資料授權交換補給便利；清除西側漂浮垃圾；東側補裝感測器並發現未明纜繩刮痕；建議收到故人聲紋商業廣告的退網老人保留原始檔、不代逝者同意。
- **第006章　晨光裡的符號（D2）**：進港採購循環機正式固定件與離線反射器，修好南側店家播放器並與聞瀾協力隔離過期授權的成人互動音源（A01）；返島解除六成負載限制；晚間繪製金屬片五種候選拓印形狀。
- **第007章　岸線的盲點（D3白天）**：海霧與側風中於東側設三處校準測點，岸上接收端出現近一秒資料空缺，並拍到航道邊緣灰白舊浮標；匿名提出港務技術詢問；為替聞瀾整理公共水位摘要而失去半個下午飛行複測時間。
- **第008章　沒有人的回聲（D3夜間）**：風雨使東側防風板墊片震動，雪鴨自內側臨時止振並封閉外側步道；關閉自動補幀保留真實波形缺口；獲港務回覆舊浮標識別服務已停用但無法證實同一性；關閉非必要訪客物流識別；雨夜訊息中與聞瀾延續不涉工作的私人約定（A02）。
- **第009章　遠處的停留（D4）**：雨後訂購正式墊片；低空飛行機與島內獨立錄音機於十點十七分取得細小反光與微弱機械聲，然對照普通船隻與金屬反射亦能重現部分波動；將額外調查列為「個人興趣」自設預算，並在訊息間留下與聞瀾喝飲料的日程空格（A03）。
- **第010章　潮汐之外（D5）**：東側內側安全區受控校準捕捉到兩次超出公共需要之外部識別詢問，依裝置容量上限自主停止並拒絕擴權；送出港務技術詢問、通知原委託人並正式將 D0 委託歸檔結案；傍晚邀聞瀾經西側訪客泊位入島共度 R18-01 親密夜晚，次日規劃進港領墊片與接下防雨棚維修。

# 第二卷〈借名航線〉｜第011～020章（D6～D19清晨，92,936 漢字）

- **第011～013章（D6～D8）**：雪鴨在港區替許姨修繕雨棚，因公共工作機事故與 36 歲持牌救援船長陸策從衝突走向合作；公開資料顯示潮幕庭同批旅客「128 入場卻先 127、後 131 離場」。D7 修好海島東側防風板並受 33 歲海生亞人芙熙正式委託限量安全核對；D8 依合法訪客許可進入潮幕庭，結識獨立成年感官服務與契約顧問尹徹，並協助安全處置七號停用泊位接駁事故。
- **第014～016章（D9～D12）**：D9 確認郭崎未結工單安全離場證明不足，尹徹離線重現舊相容性接口忽略同短代號不同發行版本；D9 夜間雪鴨與尹徹於合法預訂私人空間自願發生 R18-02；卷末拒絕四倍資訊收購與預設低風險結論的第二份報價。D10 與陸策執行外側測繪時遇海浪碰撞導致設備受損；D11 發現舊檢修孔標記與現行撤離圖錯位；D12 在合法內側檢查中實際找到仍在場館工作的郭崎，保全其離線工單與工程異議，並以受控測試發現隔水門可能過早顯示「可進入下一步封閉確認」。
- **第017～018章（D13～D14）**：沈梧經原契約保管窗口自主確認合法離場、無需救援也不公開私人行程；營運主管曹啟衡具名承認早已知悉風險警示並參與延後改善；D14 雪鴨簽署不公開無關海島資料之可追溯受限見證，正式臨時安全命令於夜間實際攔下兩名仍在工區者。
- **第019章（D15）**：真實高潮位與壓差造成 B-4 舊式排水閥與內側隔離板錯誤連動，簡化摘要仍誤顯為 0；陸策船隊與有權安全員安全救出受困的郭崎與陶蓮，梁序自上層撤出，三人全數脫險；雪鴨放棄冒險搶救易損原始波形，自己在安全觀察區被移動資料箱傷及右手腕。
- **第020章（D16～D19清晨）**：有權去識別稽核釐清 128 入、127 初報／131 後報係由一筆晚到正常離場與三筆短代號重發／轉接重複事件構成，核心失誤在簡化結束狀態被誤用於具名工人簽退並疊加延後改善與現場操作；B-4 持續受限，曹啟衡暫停受影響區最終獨立簽核，行政與保險程序續行。雪鴨獲分段工作報酬（傷勢與設備停工損失尚待核結）。D18 雪鴨邀陸策以私人訪客來島並自願發生 R18-03，D19 早晨陸策依規離島後，雪鴨收到獨立的遠嶺移動街區委託邀約，只詢價與確認傷後條件、尚未接案。
