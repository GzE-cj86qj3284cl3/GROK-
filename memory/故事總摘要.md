# 故事總摘要

## 第001章後

雪鴨在私人海島度過平靜的早晨，完成日常洗漱與簡單料理後，透過攜帶型終端接獲一則高報酬的匿名委託。

委託內容為至某居住核外環的灰域，尋找並帶回一件私人遺物——一塊表面刻有特殊符號的金屬片。委託人強調不希望留下標準化紀錄。

雪鴨在確認預付款與遺物照片後發現，其上的符號與自己體內未知晶片中曾破解出的難解符號高度相似。她決定接受委託，並提前結束海島的早晨，前往裝備間準備出發。

目前故事正式展開，核心謎團（未知晶片與符號）首次以「第二塊實體」的形式浮現。

## 第002章後

雪鴨驅使小型飛行載具抵達灰域，在舊存儲區取得刻有相似符號的金屬片。過程中與一名看守中間人簡短接觸，并感覺到遠處似有其他目光監視。金屬片與體內晶片產生微微熱度回應，關聯性進一步確認。她搶回遺物後立即返回，未深入調查。
