# 故事總摘要

## 第001章後

雪鴨在私人海島度過平靜的早晨，完成日常洗濟與簡單料理後，透過攜帶型終端接獲一則高報酬的匿名委託。

委託內容為至某居住核外環的灰域，尋找並帶回一件私人遺物——一塊表面刻有特殊符號的金屬片。委託人強調不希望留下標準化紀錄。

雪鴨在確認預付款與遺物照片後發現，其上的符號與自己體內未知晶片中曾破解出的難解符號高度相似。她決定接受委託，並提前結束海島的早晨，前往裝備間準備出發。

目前故事正式展開，核心謎團（未知晶片與符號）首次以「第二塊實體」的形式浮現。

## 第002章後

雪鴨駆使小型飛行載具抵達灰域，在舊存儲區取得刻有相似符號的金屬片。過程中與一名看守中間人簡短接觸，并感覺到遠處似有其他目光監視。金屬片與體內晶片產生微微熱度回應，關聯性進一步確認。她搶回遺物後立即返回，未深入調查。

## 第003章後

雪鴨返回海島據點，洗濟後與委託人連絡。委託人指示保管金屬片，不要外傳，並表示後續指示會再連絡。她在海島安靜度過下午，繼續觀察金屬片與體內晶片的回應，並對灰域的監視目光保持警覺。故事進入保管與等待階段。

## 第004章後

雪鴨在海島東側平台完成遺物交付。金屬片交出後，體內熱度降低但未完全消失，委託人接觸乾脆，尾款到賬。她對對方的短暫接觸與眼神保持警覺，感覺事情尚未結束。

## 第005章後

雪鴨在交付次日晨間醒來，體內殘留熱度仍在。完成洗濟與早餐後，收到委託人確認訊息，要求保持觀察異常回應。她將符號照片存入本地加密，對昨夜接觸保持警覺，海島日常繼續。
