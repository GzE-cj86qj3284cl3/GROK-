# 故事總摘要

## 第001章後

雪鴨在私人海島度過平靜的早晨，完成日常洗澡與簡單料理後，透過攜帶型終端接獲一則高報酬的匿名委託。

委託內容為至某居住核外環的灰域，尋找並帶回一件私人遺物——一塊表面刻有特殊符號的金屬片。委託人強調不希望留下標準化紀錄。

雪鴨在確認預付款與遺物照片後發現，其上的符號與自己體內未知晶片中曾破解出的難解符號高度相似。她決定接受委託，並提前結束海島的早晨，前往裝備間準備出發。

目前故事正式展開，核心謎團（未知晶片與符號）首次以「第二塊實體」的形式浮現。

## 第002章後

雪鴨駆使小型飛行載具抵達灰域，在舊存儲區取得刻有相似符號的金屬片。過程中與一名看守中間人簡短接觸，并感覺到遠處似有其他目光監視。金屬片與體內晶片產生微微熱度回應，關聯性進一步確認。她搶回遺物後立即返回，未深入調查。

## 第003章後

雪鴨返回海島，在飛行途中與抵達後細看金屬片。貼近小腹時子宮深處晶片產生更明顯熱度與收縮回應，並引發身體敏感。她聯絡委託人回報取得，委託人詢問符號有無異常回應，她保留部分資訊回復。洗澡後仍感覺熱度存在，將金屬片收好後靜思過去。

## 第004章後

雪鴨在海島東側平台完成金屬片交付。對方語氣平靜、動作乾脆，確認一致後立即離開。交付過程中身體殘留熱度與敏感依舊存在，她對對方的眼神與過於乾脆的結束留下輕微警覺。

## 第005章後

交付完成後回到據點，確認尾款。身體殘熱仍在，洗澡時感覺更清楚。她安靜休息，對交付過程留下疑問，決定明日再觀察身體回應與後續。

## 第006章後

隔日殘留熱度逐漸退去。日常料理與陽臺靜思中，無新聯絡。她保持對委託人行為的觀察，身體回應已平復，心裡疑問仍留。
